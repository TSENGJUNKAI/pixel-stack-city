# 像素疊城 Pixel Stack City

用疊疊樂蓋房子、從上帝視角經營城市的像素風網頁遊戲。打開瀏覽器就能玩，不用安裝。

## 怎麼玩

**疊樓**
1. 用「蓋樓」點道路旁的空地，選房型，進入疊樓。樓層會左右移動，點一下（或按空白鍵）放下；對準就是「完美」，連擊越多畫面越熱鬧、音樂也會多一層。
2. 偶爾出現金色樓層（對準有大獎勵）和重樓層（比較難對，但住的人多一倍）。完美收尾可以裝屋頂花園、停機坪或霓虹招牌。
3. 完工時可以「加碼」再疊 3 層：全部完美獎勵翻倍，中途倒塌扣回一半完美獎勵。
   - 每次疊樓會隨機遇到工地狀況：吊車擺盪、軟地基搖晃、趕工加速、金幣雨、陣風。
   - 每次疊樓附一個工程委託（例如連續完美 4 次），完成有額外獎勵。
   - 道具：慢動作、磁鐵、加寬（按 1、2、3 使用），連擊 5 次會獲得一個。
   - 不想疊的時候可以選「快速施工」，多付一倍費用直接蓋好，精準度 70%。
4. 房子有木屋、日式、英式、台式等造型。公寓周圍 8 格要有小房子，大樓周圍要有 2 棟公寓。

**城市與關卡**
5. 從 16×12 的小地圖開始。達成過關條件（人口和幸福度）就能建立下一座更大的城市，最大到 44×28。
6. 每座城市有自己的名字、金幣和地形主題：河谷、海岸、山城、島嶼、雪國、古都。城市之間可以互送金幣，沒在玩的城市以一半速度累積收入。
7. 城市人口和總人口分開計算。總人口越多，市長稱號越高，還會送扭蛋券。
8. 每 28 天（一年）有年度城市評鑑，依宜居、成長、交通、建築品質、多樣性、韌性打 1～5 顆星。

**運氣**
9. 有鳥居或神社的城市每天可以抽御神籤，大吉到大凶會影響當天的疊樓和收入。
10. 彩券行每週開獎，每週最多買 10 張。
11. 扭蛋機可以抽 9 種稀有房屋外觀（R／SR／SSR），有保底，重複的會變成碎片可以兌換。

**保衛城市**
12. 第 6 天之後，機器人軍團、外星人艦隊或巨大怪獸可能來襲，它們會打掉樓層（但不會整棟摧毀）。
13. 用「防衛」蓋防衛塔、防空砲、雷達站、軍營、戰車廠和空軍基地。入侵時可以請其他城市派兵支援。

**其他**
14. 公園、商店、學校、醫院、和風建築（鳥居、日式庭園、溫泉、五重塔、神社）、地標、跨河大橋讓城市更幸福、更賺錢。
15. 四季輪替，還有地震、颱風、停電、煙火節、夏祭り、選舉、外星人來訪等事件，居民也會提出請求。
16. 39 個任務、45 個成就，還有全玩家同題的每日挑戰。
17. 高樓擋住後面時，點右下角「透」或按 X 開啟透視模式。

遊戲會自動存檔在你的瀏覽器裡。

## 操作

| 動作 | 滑鼠／觸控 | 鍵盤 |
| --- | --- | --- |
| 移動地圖 | 拖曳 | 方向鍵 / WASD |
| 縮放 | 滾輪、雙指縮放、右下角 + − | `+` `-` |
| 切換工具 | 點下方工具列 | `1`–`9`、`0` |
| 放下樓層 | 點疊樓畫面 | 空白鍵 / Enter |

## 開發

整個遊戲就是一個 HTML 檔，沒有任何相依套件。

- `pixel-stack-city.html`：遊戲本體（頁面片段，沒有 `<html>` 外框）
- `build.sh`：把遊戲本體包成完整的 `index.html`
- `index.html`：GitHub Pages 實際提供的頁面

改完 `pixel-stack-city.html` 後執行：

```sh
sh build.sh
```
