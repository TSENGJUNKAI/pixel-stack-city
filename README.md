# 像素疊城 Pixel Stack City

用疊疊樂蓋房子、從上帝視角經營城市的像素風網頁遊戲。打開瀏覽器就能玩，不用安裝。

## 怎麼玩

1. 用「蓋樓」點道路旁的空地，選房型，進入疊樓。
2. 樓層會左右移動，點一下（或按空白鍵）放下。超出下層的部分會被切掉；對準就是「完美」，連續 3 次完美樓層會變寬，連擊越多畫面越熱鬧、音樂也會多一層。
3. 偶爾出現金色樓層（對準有大獎勵）和深色的重樓層（比較難對，但住的人多一倍）。最後一層完美收尾，可以幫公寓和大樓裝上屋頂花園、停機坪或霓虹招牌。
4. 疊越高住越多人，人口帶來金幣。疊得越整齊，居民越幸福，也越耐震。
5. 公園、商店、學校、醫院讓居民更幸福；靠水和山丘的房子比較搶手；工廠很賺錢但有污染；地標和體育場吸引觀光客。
6. 地圖上有河流、湖泊和山丘，河上可以蓋橋。人口多了會塞車，要多鋪路、做出環狀道路。
7. 城市從村莊升級成小鎮、城市、大都會，每一級音樂都不同。小鎮之後可以買地擴張，也能蓋 2×2 的醫院、購物中心和體育場。
8. 四季輪替（每季 7 天）：春天櫻花、夏天煙火、秋天落葉、冬天下雪（下雪天疊樓會滑）。還會有地震、颱風、停電、煙火節、觀光團、市集日、外星人來訪，以及每 10 天一次的市長選舉。
9. 居民會提出請求（例如想要附近有公園），完成有獎勵。
10. 跟著左上角的 24 個任務走，收集 26 個成就。
11. 右上角「每日挑戰」每天一題，所有玩家題目都一樣，可以複製成績跟朋友比分數。

遊戲會自動存檔在你的瀏覽器裡。

## 操作

| 動作 | 滑鼠／觸控 | 鍵盤 |
| --- | --- | --- |
| 移動地圖 | 拖曳 | 方向鍵 / WASD |
| 縮放 | 滾輪、雙指縮放、右下角 + − | `+` `-` |
| 切換工具 | 點下方工具列 | `1`–`9`、`0` |
| 放下樓層 | 點疊樓畫面 | 空白鍵 / Enter |

## 開發

整個遊戲就是一個 HTML 檔，沒有任何相依套件。

- `pixel-stack-city.html`：遊戲本體（頁面片段，沒有 `<html>` 外框）
- `build.sh`：把遊戲本體包成完整的 `index.html`
- `index.html`：GitHub Pages 實際提供的頁面

改完 `pixel-stack-city.html` 後執行：

```sh
sh build.sh
```
