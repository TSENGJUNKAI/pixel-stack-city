# 像素疊城 Pixel Stack City

用疊疊樂蓋房子、從上帝視角經營城市的像素風網頁遊戲。打開瀏覽器就能玩，不用安裝。

## 怎麼玩

1. 用「蓋樓」點道路旁的空地，選房型，進入疊樓。
2. 樓層會左右移動，點一下（或按空白鍵）放下。超出下層的部分會被切掉；對準就是「完美」，連續 3 次完美樓層會變寬。
3. 疊越高住越多人，人口帶來金幣。疊得越整齊，居民越幸福，也越耐震。
4. 公園、商店、學校讓居民更幸福；工廠很賺錢但有污染；地標吸引觀光客。
5. 每天天氣不同，偶爾會有地震、颱風、觀光團和市集日。
6. 跟著左上角的任務走，解鎖公寓、大樓和三座地標，順便收集 14 個成就。

遊戲會自動存檔在你的瀏覽器裡。

## 操作

| 動作 | 滑鼠／觸控 | 鍵盤 |
| --- | --- | --- |
| 移動地圖 | 拖曳 | 方向鍵 / WASD |
| 縮放 | 滾輪、右下角 + − | `+` `-` |
| 切換工具 | 點下方工具列 | `1`–`9` |
| 放下樓層 | 點疊樓畫面 | 空白鍵 / Enter |

## 開發

整個遊戲就是一個 HTML 檔，沒有任何相依套件。

- `pixel-stack-city.html`：遊戲本體（頁面片段，沒有 `<html>` 外框）
- `build.sh`：把遊戲本體包成完整的 `index.html`
- `index.html`：GitHub Pages 實際提供的頁面

改完 `pixel-stack-city.html` 後執行：

```sh
sh build.sh
```
